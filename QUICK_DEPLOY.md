## 🎨 Deploy Frontend (Vercel)

### Dashboard Method:
1. https://vercel.com → "Add New Project"
2. Import GitHub repo
3. Add environment variables:
   ```
   VITE_API_URL=https://your-api-name.onrender.com
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJh...your-key
   ```
4. Click "Deploy"

### CLI Method:
```bash
npm i -g vercel
vercel login
vercel --prod
```

## ⚙️ Deploy Backend (Render)

### Dashboard Method:
1. https://render.com → "New Web Service"
2. Connect GitHub repo
3. Settings:
   - **Name:** `fundamental-analysis-api`
   - **Root Directory:** `backend`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Add environment variables (copy from `backend/.env.example`)
5. Click "Create Web Service"

## 🗄️ Set Up Database (Supabase)

1. https://supabase.com → Create new project
2. SQL Editor → Copy/paste `COMPLETE_SETUP.sql` → Run
3. Authentication → Settings:
   - Add redirect URL: `https://your-app.vercel.app/*`
   - Disable email confirmation (or configure SMTP)
4. Copy credentials:
   - Project URL: Settings → API → Project URL
   - Anon key: Settings → API → Project API keys → anon/public
   - Service key: Settings → API → Project API keys → service_role

## 🔄 After All Deployed

1. **Update Vercel** with backend URL:
   - Settings → Environment Variables
   - Update `VITE_API_URL` to your Render URL
   - Trigger redeploy

2. **Test everything:**
   ```bash
   # Backend health
   curl https://your-api.onrender.com/health
   
   # Frontend
   open https://your-app.vercel.app
   ```

3. **Register test user** and verify all features work!

## 🔧 Troubleshooting

### Backend Build Fails with pydantic-core Error
**Error:** `error: failed to create directory /usr/local/cargo/registry/cache/`

**Solution:** Python version too new (3.14) - no pre-built wheels available
- Render.yaml now specifies `pythonVersion: 3.12.0`
- Both `runtime.txt` files updated to `python-3.12.0`
- Redeploy should automatically use Python 3.12

### Backend Takes Too Long to Start
- First deploy on free tier can take 10-15 minutes
- Check Render logs for progress
- Health check endpoint: `/health`
